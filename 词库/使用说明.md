## 文件用途

- vocabulary.json：主词库、易混组、学习顺序。
- vocabulary.sqlite：同版 SQLite 数据库，含 cards、sentences、metadata；payload 保存完整 JSON。
- sentences.json：论文原句、参考译文、句法解析、上下文、版本化来源链接及关联词条。
- learning_plan.json：每课 10 词，共 190 课；只提供顺序，不是间隔复习算法。
- manifest.json：实际数量和字段缺口。
- validation.json：数据校验记录。
- SHA256SUMS.txt：主要文件摘要。
- source：原始术语来源、许可和筛选日志。
- tools：编辑源文件、重建脚本和验收脚本。

APP 可选择 JSON 或 SQLite 接入，不需要运行 Python。词卡 ID 基于规范词形；改名时需迁移学习记录。用户学习进度应单独保存。

阅读版的论文句子按浏览器本地日期轮换，也可手动选择。翻译草稿尝试保存在当前浏览器，写入失败会提示并保留页面输入；清除浏览器数据、移动文件或换浏览器可能影响读取，重要译文请复制保存。没有实现账号同步、后台提醒、间隔复习或掌握度记录。

核心释义、搭配、双语教学例句及解析为本项目编辑内容；教学例句明确标为原创，不冒充论文引文。论文短引文版权归原权利人，每篇选一句并提供出处。译文是参考答案，其中新增340句为机器初译待审校，不是作者官方译文；涉及性能或历史判断时保留范围和上下文。

方向与概念参考入口：[Google 术语表](https://developers.google.com/machine-learning/glossary)、[预测教材 FPP3](https://otexts.com/fpp3/)、[Deep Learning 概率章节](https://www.deeplearningbook.org/contents/prob.html)。这些参考不意味着每个词条都已逐条核验。

## 重建

Python 3 标准库即可。在本目录依次执行：

    python tools/build.py
    python tools/finalize.py
    python tools/render_reader.py
    python tools/validate.py

不要仅执行 build.py 后交付，它只生成基础层。修改前先保存独立版本；脚本不自动备份手工修改的交付文件。
