autocorrelation|Residual autocorrelation indicates that temporal structure may remain unexplained.|残差自相关表明，可能仍有时间结构未被解释。|这是诊断线索，不是单凭一个相关系数就确定原因。
cross-correlation|We inspect the cross-correlation between speed and traffic volume.|我们检查速度与交通量之间的互相关。|互相关研究两序列在不同相对滞后下的关联。

probabilistic forecast|A probabilistic forecast describes a distribution over future outcomes.|概率预测描述未来结果的分布。|它能表达不确定性，但是否可靠需要校准等评估。

forecast reconciliation|Forecast reconciliation makes forecasts consistent across aggregation levels.|预测协调使不同聚合层级上的预测保持一致。|例如各地区预测与总量预测满足加总约束。
Granger causality|Granger causality tests whether one series improves prediction of another.|格兰杰因果关系检验一个序列是否有助于预测另一个序列。|预测意义上的因果不自动等于干预意义上的因果关系。
hybrid neural network|The hybrid neural network combines graph convolution with recurrent updates.|该混合神经网络将图卷积与循环更新相结合。|hybrid 的具体构成必须说明，不能仅凭名称判断结构。
hybrid model|The hybrid model combines a neural component with a physical simulator.|该混合模型将神经网络组件与物理模拟器相结合。|混合模型也可组合统计模型、机制模型和神经网络。

graph neural network|A graph neural network propagates information along graph edges.|图神经网络沿图的边传播信息。|图的节点与边必须对应实际建模对象与关系。

message passing|During message passing, each node aggregates information from its neighbors.|在消息传递过程中，每个节点聚合来自邻居的信息。|消息函数、聚合函数和更新函数各有不同作用。

causal convolution|A causal convolution uses only the current and preceding inputs.|因果卷积仅使用当前及此前的输入。|此处 causal 指时间可见性，不代表模型做了因果推断。

hidden state|The recurrent unit updates its hidden state at each time step.|循环单元在每个时间步更新其隐藏状态。|LSTM 的 hidden state 与 cell state 需区分。
self-attention|Self-attention relates positions within the same input representation.|自注意力关联同一输入表征内部的位置。|相关位置可以是时间步、变量或其他 token，不能默认一定是时间。
cross-attention|Cross-attention uses queries from one stream and keys and values from another.|交叉注意力使用一个分支的查询，以及另一个分支的键和值。|应明确哪个分支提供 Q，哪个分支提供 K、V。
positional encoding|Positional encoding supplies information about the order of input tokens.|位置编码提供输入 token 的顺序信息。|绝对位置、相对位置与真实时间间隔编码并不相同。
residual connection|A residual connection adds the input of a block to its transformed output.|残差连接把模块的输入加到变换后的输出上。|相加要求维度兼容，必要时需投影。

scheduled sampling|Scheduled sampling mixes observed and predicted inputs during training.|计划采样在训练时混合使用真实输入和预测输入。|具体混合策略及其统计性质要看论文设定。

physics-informed neural network|A physics-informed neural network can penalize violations of a governing equation.|物理信息神经网络可以对违反控制方程的情况施加惩罚。|物理约束应落实到具体方程、边界条件或结构中。
likelihood|We maximize the likelihood of the observed data with respect to the model parameters.|我们针对模型参数最大化观测数据的似然。|似然把观测数据视为已知，作为参数的函数；不等同于参数的概率。
prior distribution|The prior distribution expresses assumptions about parameters before observing the current data.|先验分布表达在观察当前数据之前对参数的假设。|先验可以来自领域知识，也可以用于正则化，但必须说明。
posterior distribution|The posterior distribution combines the prior with information from the observed data.|后验分布结合了先验与观测数据中的信息。|后验是条件于观测数据的分布。
predictive distribution|The predictive distribution assigns probabilities to possible future values.|预测分布为可能的未来取值赋予概率。|连续取值使用密度，单个点的概率通常为零。
posterior predictive distribution|The posterior predictive distribution averages predictions over posterior parameter uncertainty.|后验预测分布对后验参数不确定性进行平均，从而得到预测。|与只把参数固定为某个点估计后预测不同。
conditional independence|The model assumes conditional independence given the latent state.|该模型假设在给定隐状态的条件下满足条件独立性。|条件独立不等于无条件独立。
latent variable|A latent variable represents an unobserved factor in the model.|隐变量表示模型中未被直接观测的因素。|latent variable 是建模变量，不必然对应可直接解释的真实因素。
expectation|We estimate the expectation using Monte Carlo samples.|我们使用蒙特卡洛样本估计期望。|期望是概率加权平均，不等于最可能出现的值。
variance|The variance measures dispersion around the mean.|方差度量围绕均值的离散程度。|方差的单位是原变量单位的平方；标准差保留原单位。
standard error|The standard error quantifies variability in an estimator across repeated samples.|标准误量化估计量在重复抽样中的变异程度。|标准误不是观测数据本身的标准差。

credible interval|The credible interval contains ninety-five percent of the posterior probability mass.|该可信区间包含百分之九十五的后验概率质量。|这是给定模型、先验与数据后的贝叶斯概率表述。
